<dfk-feature icon="lucide:braces" title="Colors as ordinary SQL values">
A color is one STRUCT(space, c1, c2, c3, alpha): keep it in a column, group by it, compare it, and pass it through lambdas and joins like any other value.
</dfk-feature>

<dfk-feature icon="lucide:swatch-book" title="44 color spaces">
sRGB, Display P3, Rec. 2020, CIE Lab and LCh, OKLab and OKLCh, HSLuv, CAM16 and more — construct a color in any of them and convert between all of them in one call.
</dfk-feature>

<dfk-feature icon="lucide:blend" title="Mix, blend and build schemes">
11 blend modes and 6 Porter-Duff compositing operators, lighten and darken, saturation and hue shifts, premultiplied alpha, and complementary / analogous / triadic / tetradic schemes.
</dfk-feature>

<dfk-feature icon="lucide:scale" title="Differences and contrast">
Seven color-difference metrics including CIEDE2000 and CMC, plus WCAG 2.1 relative luminance, contrast ratio and pass/fail checks against the standard criteria.
</dfk-feature>

<dfk-feature icon="lucide:palette" title="Palettes and random colors">
38 colorous gradients and 10 categorical palettes, the 148 SVG/CSS names, and seeded random sampling from palette's distributions — a colormap is one function call.
</dfk-feature>

Parse and write hex or full CSS Color Level 4, pack and unpack ARGB/RGBA/ABGR/BGRA integers, and inspect primaries, white points, transfer functions and matrices.
</dfk-feature>

## Install once, then call it from SQL

The extension adds ordinary SQL functions, with nothing to import at the call site. Install it once (left), then use the functions anywhere a DuckDB function is allowed (right).

<div className={styles.codeGrid}>

```sql title="duckdb"
-- once per installation, then once per session
INSTALL duckfn_palette FROM community;
LOAD duckfn_palette;
```

<div className={styles.codeColumn}>

```sql title="duckdb"
SELECT plt_to_hex(plt_convert(plt_srgb(1, 0.5, 0), 'oklch'));  -- #ff8000
SELECT plt_contrast(plt_named('white'), plt_named('black'));    -- 21.0
SELECT to_json(list_transform(plt_colorous_palette('viridis', 3), lambda x: plt_to_hex(x)));
-- ["#440154","#20908c","#fde725"]
```

The comments are what each call returns — a converted color, a WCAG contrast ratio, and a three-stop gradient sampled as hex.
